# Ecological translation: from organism roles to feedback positions

## Proposed abstraction

An ecological commons can be represented as a vector of shared conditions:

\[
X_t=(\text{nutrients, habitat, prey, pathogens, microclimate, spatial structure},\ldots).
\]

Each organism or population observes only a projection of this state, acts locally, and changes some components of it. A regulatory role is then not a moral property of a species but a position in a closed causal path:

\[
\text{population}\rightarrow X\rightarrow
\text{other populations}\rightarrow X\rightarrow
\text{future population}.
\]

## The blackbird question

The defensible question is not "what does a blackbird pay back to the ecosystem?" It is:

> Through which signed and delayed loops does blackbird activity alter shared conditions on which blackbirds and other populations subsequently depend?

Possible paths include insect consumption, seed movement, nutrient transport, predation, competition, pathogen transmission and behavioral effects. Their signs and strengths are empirical matters.

## What transfers from the computation model

| Computation model | Ecological question |
|---|---|
| Harmful proposal rate \(b\) | Rate or intensity of an activity that degrades a selected shared condition |
| Monitor effort \(q\) | Strength of a counteracting response elsewhere in the network |
| Monitor count \(n\) | Number of potentially corrective pathways |
| Common-mode failure \(\rho\) | Shared vulnerability that disables several pathways together |
| Detection/commitment latency | Ecological response delay |
| Commons health \(X\) | Measured shared condition, not an assumed global welfare scalar |
| Verification debt \(D\) | Candidate lagging imbalance between degrading load and corrective capacity |

## Necessary cautions

- Persistence does not imply positive net ecosystem contribution.
- Natural selection acts through differential reproduction, not a global commons objective.
- Parasites and capture regimes can persist for long periods.
- An ecosystem need not have a single scalar health measure.
- Apparent regulation can be an equilibrium consequence rather than an evolved system-level adaptation.
- A species may participate in both stabilizing and destabilizing loops at different scales.

The cross-domain hypothesis is narrower: **some ecological functions may be identifiable as positions in distributed control loops, and correlated loss of those loops may create a lower bound on correctable disturbance.** That is testable only after operational variables and causal paths are specified for a real system.
