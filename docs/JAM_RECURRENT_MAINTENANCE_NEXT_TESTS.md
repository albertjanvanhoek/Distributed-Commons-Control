# Next tests after formal closure

Once the new Lean target is green, the highest-value follow-up tests are empirical/model-grounding rather than more algebra.

1. Map which JAM/staking/operator mechanisms could instantiate `C -> O`, `O -> R`, and `R -> C`.
2. Determine which of those mappings are specified, delegated, or absent in the current Gray Paper/staking design.
3. Measure or bound whether effort/client diversity signals discriminate independently corrective capacity rather than nominal participation.
4. Test whether return/reward is correlated with future independent corrective capacity.
5. Stress the phase diagram under turnover, multiple overlapping fault domains, and non-linear resource return.
6. Only after those checks consider a general matrix/spectral model; the current three-cycle is deliberately the minimal auditable case.
