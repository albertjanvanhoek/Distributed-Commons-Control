# Mapping the generic model to JAM

## Boundary of the mapping

JAM motivated the test case because it makes production, checking, availability and commitment explicit. The generic model is not a faithful reduction of the full protocol and is not a security audit. Names in the right column identify possible correspondences to investigate, not equivalences already proved.

| Generic object | JAM-facing interpretation to investigate |
|---|---|
| Producer | Actor producing a work result or report |
| Harmful proposal | Invalid or otherwise non-admissible result presented for commitment |
| Monitor | Guarantor, assurer, auditor or dispute participant, depending on stage |
| Observation channel | Evidence available for checking work or availability |
| Common-mode failure \(\rho\) | Correlated implementation, information, incentive or assignment failure |
| Commitment | Accumulation/finalization of an accepted state transition |
| Commons state | Protocol-valid shared state and the capacities needed to continue maintaining it |
| Monitoring cost | Compute, bandwidth, latency, opportunity cost or risk borne by checkers |
| Safety target \(\varepsilon\) | Declared upper bound on an operational failure event |
| Verification debt | Candidate measure of corrective demand exceeding effective checking margin |

## Why the commons is not simply truth

Consensus can establish that a transition is valid under declared protocol rules and assumptions. It does not by itself establish truth about the external world. The shared object studied here is therefore **protocol-valid state plus the architecture capable of maintaining it**.

## Questions generated by the model

1. Which JAM failure modes are plausibly independent, and which are common-mode?
2. Can assignment rotation reduce \(\rho\), or does it only increase nominal monitor count \(n\)?
3. Are rewards tied to nominal participation, useful detection, availability, or successful correction?
4. Does growth in refinement throughput increase corrective demand faster than checking capacity?
5. Which observable variables would reveal declining correction margin before invalid finalization occurs?
6. Which protocol mechanisms alter selected effort, and which alter sufficient effort?

Answering these requires the exact Gray Paper mechanisms and, eventually, protocol experts. The toy model tells us what distinctions to measure; it does not supply their empirical values.
