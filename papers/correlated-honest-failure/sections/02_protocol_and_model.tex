\section{Protocol and model}
\label{sec:model}

\subsection{JAM/ELVES audit structure}

The present paper treats ELVES as the execution-auditing abstraction and the JAM Gray Paper as the protocol-facing specialization. The key architectural feature is sampled re-execution with escalation: a small initial set checks a report, and unresolved disagreement recruits further checking capacity. The exact JAM verdict layer then aggregates judgments into good, bad or wonky outcomes.

We keep three levels separate throughout:
\begin{enumerate}[leftmargin=*]
\item the \emph{verdict rule}: which collections of judgments permit a good, bad or wonky verdict;
\item the \emph{audit branching model}: how independently correct checking reproduces during escalation;
\item the \emph{cross-audit maintenance model}: how the capacity supplying independent correction is retained, observed and resourced across time.
\end{enumerate}

Only the first is a direct Gray Paper rule. The second is inherited from ELVES and extended by a correlated-fault partition. The third is introduced in Results 4--5 as a declared systems model.

\subsection{Fault-specific validator classes}

Fix one invalid report and one fault family $x$. Partition the validator set into:
\begin{itemize}
\item $A$: adversarial validators;
\item $B_x$: otherwise-honest validators whose shared fault causes the report to be judged valid;
\item $C_x$: validators that independently judge the report invalid.
\end{itemize}
Thus
\[
N=A+B_x+C_x.
\]
The adjective \emph{independently correct} is fault-specific. It does not imply globally independent software, nor does membership in $B_x$ imply that a validator is generally unreliable.

Define
\[
\gamma=\frac{A}{N},
\qquad
f_x=\frac{B_x}{N-A},
\qquad
h_x=\frac{C_x}{N}=(1-\gamma)(1-f_x),
\]
and
\[
p_x=1-h_x=\gamma+(1-\gamma)f_x.
\]
Here $p_x$ is the maximum share that can return a wrong positive judgment for the declared report if adversarial validators coordinate with the shared fault.

\subsection{Verdict threshold}

For verdict-set size $N$, write
\[
K=\floor{\frac{2N}{3}}+1.
\]
The analysis uses the Gray Paper verdict composition rules exactly as stated in the protocol snapshot cited in this repository. A bad verdict requires a qualifying set containing no positive judgments. Therefore independently correct negative judgments can construct a bad verdict against adversarial positive voting iff
\[
C_x\ge K.
\]
This result is independent of the ELVES branching approximation.

\subsection{Fault-specific audit reproduction}

For the ELVES-style escalation extension, let $F$ denote the tranche/escalation factor. Replacing the independently honest share by the fault-specific independently correct share yields the declared reproduction mean
\[
\lambda_x=Fh_x=F\frac{C_x}{N}=F(1-\gamma)(1-f_x).
\]
The supercritical condition is
\[
\lambda_x>1.
\]
This substitution is a model extension and is not presented as a theorem from the original ELVES paper.

\subsection{Slow corrective-capacity state}

Results 4--5 add a separate cross-audit state. To avoid confusing a count with a normalized state variable, write
\[
c_{x,t}\in\mathbb R
\]
for the model's normalized fault-specific independently corrective coordinate at slow time $t$. In the simplest mapping to the static partition, $c_{x,t}$ corresponds to an effective independently correct share like $C_{x,t}/N_t$, but the dynamic model leaves empirical construction of this quantity open.

The remaining coordinates are
\[
o_t=\text{maintenance observability/attribution capacity},
\qquad
r_t=\text{returned-resource capacity}.
\]
For readability, the later dynamic sections denote these three coordinates by capital letters $(C_t,O_t,R_t)$; there $C_t$ is a normalized slow-state coordinate, not the earlier validator count $C_x$.

The declared linear update is
\begin{align}
C_{t+1}&=r_C C_t+k_{RC}R_t,\\
O_{t+1}&=r_O O_t+k_{CO}C_t,\\
R_{t+1}&=r_R R_t+k_{OR}O_t.
\end{align}
Coupling the slow corrective coordinate to the next audit gives
\[
\lambda_{x,t}=F C_t.
\]
No claim is made that the Gray Paper already contains these state variables or linear coefficients. They are introduced to expose which additional empirical quantities are required if current audit correction is to be translated into a claim about persistence of correction.

\subsection{Claim hierarchy}

The model therefore has an explicit hierarchy:
\begin{enumerate}[leftmargin=*]
\item exact verdict arithmetic under the Gray Paper rules and declared fault partition;
\item ELVES-style branching consequences under the substitution $h_x=C_x/N$;
\item slow maintenance replacement consequences under declared $C\to O\to R\to C$ dynamics;
\item finite-horizon implications after coupling $C_t$ back to $\lambda_{x,t}$.
\end{enumerate}
The claim ledger records these levels separately so that a failure of a higher-level mapping does not invalidate lower-level protocol arithmetic.
